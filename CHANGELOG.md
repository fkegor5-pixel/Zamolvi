# История изменений

## 3.3.1 — сервер 3.2.1

- Новые стили-персонажи: Компьютер (отвечает двоичным кодом), Болотный огр, Зелёный громила,
  Пират, Рыцарь, Мудрый магистр, Мультяшный злодей, Кот.

## 3.3 — сервер 3.2.0

- **Стиль общения** («3. Нейросеть и текст» → «Стиль общения»): Обычный, Добрый, Миролюбивый,
  Деловой, Дерзкий, Гопник, Умник, Саркастичный, Шутник, Философ. Стиль добавляется к вашей
  инструкции и действует для ответов в Telegram, из уведомлений и в проверке AI.

## 3.2.1

- Ответы из уведомлений работают в фоне и при выключенном экране: кнопка «Снять ограничение
  батареи», удержание процессора на время ответа, повторное подключение к уведомлениям, если
  оболочка телефона выгрузила приложение.
- «Проверка функций» предупреждает, если батарея ограничивает работу в фоне.

## 3.2

- Ответы из уведомлений: режим «Всем личным чатам, кроме игнора».
- Список «Кому ответил»: имя, число ответов, время последнего, кнопка «В игнор».
- Список «Игнор» с кнопкой «Убрать из игнора».
- Служебный чат «Telegram» с кодами входа никогда не отправляется на сервер и не получает ответа.

## 3.1.2

- Ответы из уведомлений: свой автоответ теперь узнаётся по пометке «[AI-автоответ]», а не по
  полю отправителя — некоторые версии Telegram оставляют его пустым и для входящих, из-за
  чего ответы не отправлялись.
- Экран показывает, почему последнее уведомление Telegram пропущено (нет в списке, групповой
  чат, скрыт текст и т. д.), и проверяет ответ сервера кнопкой «Проверить ответ сервера».
- Поддержаны Telegram Plus, Telegram X, Nekogram и NekoX.

## 3.1.1 — сервер 3.1.1

- Если в поле модели вставлен API-ключ, сервер не сохраняет его и не показывает в
  ошибках; уже сохранённый так ключ удаляется при обновлении сервера.
- «Проверка функций» показывает состояние ответов из уведомлений: доступ, список чатов,
  последний ответ или ошибка.

## 3.1 — сервер 3.1.0

- **Ответы из уведомлений** («2. Telegram» → «Ответы из уведомлений»): автоответ без входа
  в Telegram на сервере. Приложение читает уведомления Telegram на телефоне, сервер
  составляет ответ выбранной нейросетью, ответ уходит кнопкой «Ответить» из уведомления.
  Отвечает только личным чатам из списка, не чаще раза в 20 секунд на чат, на свои же
  ответы не реагирует. На сервер передаётся только текст сообщения.
- В подробной статистике — отдельная строка «Ответы из уведомлений».

## 3.0 — сервер 3.0.0

- Новое название — **Zamolvi**: на значке, в меню, виджете, уведомлениях,
  на странице QR-входа и в списке устройств Telegram. Внутренние идентификаторы
  сохранены, поэтому версия ставится поверх предыдущих, а сервер обновляется
  без потери настроек и входа.
- Обновлены описания на экранах «Как это работает», «Память собеседников»,
  «Фото и документы» и «Подробная статистика».
- Подсказка про фоновые ограничения в «Проверке функций» теперь работает для
  всех производителей с агрессивной экономией батареи.
- Ошибки AI API понятнее: если OpenRouter и похожие сервисы возвращают ошибку
  внутри ответа, виден её текст; при лимите бесплатной модели запрос
  повторяется позже; если «думающая» модель израсходовала токены на рассуждения,
  об этом прямо написано; при HTTP 400/404 видны модель и ответ провайдера.
- Для обновления памяти у провайдеров, кроме Groq, лимит ответа увеличен до
  4096 токенов.
- Видео-заставка больше не входит в проект: можно добавить своё
  (см. `assets/README.md`).
