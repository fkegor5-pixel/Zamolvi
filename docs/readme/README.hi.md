# Zamolvi

[English](../../README.md) · [Русский](README.ru.md) · [Español](README.es.md) · [Português](README.pt.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [Türkçe](README.tr.md) · [Polski](README.pl.md) · [Українська](README.uk.md) · [العربية](README.ar.md) · **हिन्दी** · [Bahasa Indonesia](README.id.md) · [中文](README.zh.md) · [日本語](README.ja.md)

**Telegram की निजी चैट के लिए AI ऑटो-रिस्पॉन्डर, जो आपके अपने सर्वर पर चलता है।**

जब आप व्यस्त हों, Zamolvi आपके संपर्कों को जवाब देता है: नया संदेश प्राप्त करता है, उसे आपके चुने हुए AI को भेजता है और आपकी ओर से जवाब भेजता है — केवल उन निजी चैट में जिन्हें आपने चुना है। इसे Android ऐप से नियंत्रित किया जाता है और काम आपके VPS पर होता है, इसलिए आप ऐप बंद करके फ़ोन लॉक कर सकते हैं।

## सुविधाएँ

| अनुभाग | क्या करता है |
|---|---|
| 1. VPS कनेक्शन | SSH से आपके VPS पर सर्वर इंस्टॉल और अपडेट करता है, HTTPS सेट करता है |
| 2. Telegram | कोड या QR और क्लाउड पासवर्ड से लॉगिन। साथ ही **सूचनाओं से जवाब** — सर्वर पर Telegram लॉगिन के बिना |
| 3. AI और टेक्स्ट | प्रदाता, मॉडल, कुंजी, निर्देश और फ़ॉर्मैटिंग, परीक्षण। साथ ही **बातचीत की शैली**: दयालु, ढीठ, टपोरी, ज्ञानी, समुद्री डाकू, कंप्यूटर आदि |
| 4. निजी चैट | ऑटो-रिस्पॉन्डर किन संपर्कों को जवाब दे |
| 5. ऑटो-रिस्पॉन्डर | चालू और बंद, स्थिति, शांत घंटे, कई संदेशों की प्रतीक्षा |
| 6. सर्वर लॉग | घटनाएँ और निदान |
| 7. यह कैसे काम करता है | ऐप और लेखक के बारे में |
| 8. आँकड़े | दिन के अनुसार जवाब, वॉइस संदेश और त्रुटियाँ |
| 9. ऐप थीम | हल्की, गहरी या सिस्टम। साथ ही **इंटरफ़ेस की भाषा** |
| 10. हटाए गए संदेश | चुनी गई चैट में हटाए गए संदेशों का संग्रह (30 दिन तक), खोज सहित |
| 11. संपर्क स्मृति | हर संपर्क का सारांश: नाम, रुचियाँ, समझौते, मुख्य तथ्य; «भूल जाएँ» बटन; आपके आदेश पर इतिहास लोड करना |
| 12. फ़ोटो और दस्तावेज़ | फ़ोटो का टेक्स्ट और विवरण; PDF, DOCX, TXT, CSV, JSON पढ़ना |
| 13. जवाब की मंज़ूरी | ड्राफ़्ट: भेजने से पहले भेजें, बदलें या अस्वीकार करें |
| 14. विस्तृत आँकड़े | AI की लागत, मॉडल और चैट के अनुसार खर्च, जवाब का समय, त्रुटियाँ |
| 15. सुविधा जाँच | क्या काम करता है, क्या नहीं और क्यों — सुधार बटनों के साथ |

इसके अलावा: वॉइस संदेशों का ट्रांसक्रिप्शन (Groq के ज़रिए Whisper), विजेट, स्थायी सूचना और त्वरित सेटिंग टाइल, संपर्क के लिए `/ai_off` कमांड, शांत घंटे और कई संदेशों का एक साझा जवाब।

## आवश्यकताएँ

- Android 9 या नया।
- Debian 12 या Ubuntu 24.04, सार्वजनिक IPv4 और root SSH पहुँच वाला VPS।
- [my.telegram.org](https://my.telegram.org) से आपके अपने Telegram `api_id` और `api_hash` (सूचनाओं से जवाब के लिए आवश्यक नहीं)।
- AI API कुंजी: **Groq** (मुफ़्त योजना उपलब्ध), **Google Gemini**, **GigaChat** या कोई भी **OpenAI-संगत API** (जैसे OpenRouter)।

## त्वरित शुरुआत

1. **Releases** से APK डाउनलोड करके इंस्टॉल करें।
2. **1. VPS कनेक्शन**: पता और root पासवर्ड डालें, «ऐप से सर्वर इंस्टॉल करें» दबाएँ।
3. **2. Telegram**: `api_id`, `api_hash` और नंबर डालें, कोड या QR से लॉगिन करें। या बिना लॉगिन के काम के लिए «सूचनाओं से जवाब» खोलें।
4. **3. AI और टेक्स्ट**: प्रदाता, कुंजी और मॉडल चुनें, निर्देश लिखें और «जाँचें» दबाएँ। चाहें तो शैली चुनें।
5. **4. निजी चैट**: संपर्क चुनें।
6. **5. ऑटो-रिस्पॉन्डर**: चालू करें।

अगर कुछ काम न करे, तो **15. सुविधा जाँच** खोलें: वहाँ कारण और उपाय दिखेगा।
