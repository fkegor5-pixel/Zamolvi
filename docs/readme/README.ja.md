# Zamolvi

**自分のサーバーで動く、Telegram 個人チャット用の AI 自動応答。**

忙しいときに Zamolvi が相手に返信します。新しいメッセージを受け取り、選んだ AI に渡して、あなたの名前で返信を送ります——選んだ個人チャットだけで。操作は Android アプリから行い、処理は自分の VPS で動くので、アプリを閉じて端末をロックしても大丈夫です。

## 機能

| セクション | 内容 |
|---|---|
| 1. VPS 接続 | SSH で VPS にサーバーをインストール・更新し、HTTPS を設定 |
| 2. Telegram | コードまたは QR とクラウドパスワードでログイン。さらに、サーバーで Telegram にログインせずに使える**通知からの返信** |
| 3. AI とテキスト | プロバイダー、モデル、キー、指示、返信の書式、テスト。さらに**会話スタイル**：やさしい、生意気、ヤンキー、物知り、海賊、コンピューターなど |
| 4. 個人チャット | 自動応答する相手の選択 |
| 5. 自動応答 | 開始と停止、状態、おやすみ時間、連続メッセージの待機 |
| 6. サーバーログ | イベントと診断 |
| 7. しくみ | アプリと作者について |
| 8. 統計 | 日ごとの返信、ボイスメッセージ、エラー |
| 9. テーマ | ライト、ダーク、システム。さらに**表示言語** |
| 10. 削除されたメッセージ | 選んだチャットで削除されたメッセージのアーカイブ（最大 30 日、検索可） |
| 11. 相手の記憶 | 相手ごとの要約：名前、興味、約束、重要な事実。「忘れる」ボタン。指示によるチャット履歴の読み込み |
| 12. 写真と文書 | 写真の文字と説明。PDF、DOCX、TXT、CSV、JSON の読み取り |
| 13. 返信の承認 | 下書き：送信前に送信・修正・却下 |
| 14. 詳細統計 | AI の費用、モデル別・チャット別の支出、返信時間、エラー |
| 15. 機能チェック | 何が動き、何が動かないか、その理由。修正ボタン付き |

ほかに：ボイスメッセージの文字起こし（Groq 経由の Whisper）、ウィジェット、常駐通知とクイック設定タイル、相手が自動応答を止める `/ai_off` コマンド、おやすみ時間、複数メッセージへのまとめ返信。

## 必要なもの

- Android 9 以降。
- Debian 12 または Ubuntu 24.04、グローバル IPv4、root の SSH アクセスがある VPS。
- [my.telegram.org](https://my.telegram.org) で取得した自分の Telegram `api_id` と `api_hash`（通知からの返信では不要）。
- AI の API キー：**Groq**（無料枠あり）、**Google Gemini**、**GigaChat**、または任意の **OpenAI 互換 API**（例：OpenRouter）。

## クイックスタート

1. **Releases** から APK をダウンロードしてインストール。
2. **1. VPS 接続**：アドレスと root パスワードを入力し、「アプリからサーバーをインストール」をタップ。
3. **2. Telegram**：`api_id`、`api_hash`、電話番号を入力し、コードまたは QR でログイン。ログインせずに使うなら「通知からの返信」を開く。
4. **3. AI とテキスト**：プロバイダー、キー、モデルを選び、指示を書いて「テスト」をタップ。お好みでスタイルを選択。
5. **4. 個人チャット**：相手にチェック。
6. **5. 自動応答**：オンにする。

うまく動かないときは **15. 機能チェック** を開くと、原因と対処が表示されます。

## プライバシーと責任ある利用

- メッセージは選んだ AI プロバイダーにだけ、選んだチャットの分だけ送られます。詳細：[PRIVACY.md](../../PRIVACY.md)、[SECURITY.md](../../SECURITY.md)。
- AI が返信する場合があることを相手に伝え、同意なく履歴を読み込まないでください。
- [Telegram API 利用規約](https://core.telegram.org/api/terms)を守り、スパムや一斉送信はしないでください。
