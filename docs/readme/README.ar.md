**مجيب آلي بالذكاء الاصطناعي للمحادثات الخاصة في تيليجرام، يعمل على خادمك الخاص.**

يرد Zamolvi على جهات اتصالك عندما تكون مشغولًا: يستقبل الرسالة الجديدة، ويمررها إلى الذكاء الاصطناعي الذي اخترته، ويرسل الرد باسمك — فقط في المحادثات الخاصة التي اخترتها. تتحكم به من تطبيق أندرويد، بينما يجري العمل على خادم VPS الخاص بك، لذا يمكنك إغلاق التطبيق وقفل الهاتف.

## الميزات

| القسم | ما يفعله |
|---|---|
| 1. الاتصال بـ VPS | يثبّت الخادم ويحدّثه عبر SSH ويضبط HTTPS |
| 2. Telegram | تسجيل الدخول برمز أو QR مع كلمة المرور السحابية، و**الرد من الإشعارات** دون تسجيل دخول تيليجرام على الخادم |
| 3. الذكاء الاصطناعي والنص | المزوّد والنموذج والمفتاح والتعليمات وتنسيق الردود والاختبار، و**أسلوب التواصل**: لطيف، جريء، شقي، متحذلق، قرصان، حاسوب وغيرها |
| 4. المحادثات الخاصة | جهات الاتصال التي يرد عليها المجيب |
| 5. المجيب الآلي | التشغيل والإيقاف، الحالة، ساعات الهدوء، انتظار عدة رسائل |
| 6. سجل الخادم | الأحداث والتشخيص |
| 7. كيف يعمل | عن التطبيق والمؤلف |
| 8. الإحصاءات | الردود والرسائل الصوتية والأخطاء يوميًا |
| 9. سمة التطبيق | فاتحة أو داكنة أو حسب النظام، و**لغة الواجهة** |
| 10. الرسائل المحذوفة | أرشيف الرسائل المحذوفة في المحادثات المختارة (حتى 30 يومًا) مع البحث |
| 11. ذاكرة جهات الاتصال | ملخص لكل جهة اتصال: الاسم، الاهتمامات، الاتفاقات، الحقائق المهمة؛ زر «انسَ»؛ تحميل السجل بأمرك |
| 12. الصور والمستندات | نص الصور ووصفها؛ قراءة PDF وDOCX وTXT وCSV وJSON |
| 13. اعتماد الردود | مسودات: إرسال أو تعديل أو رفض قبل الإرسال |
| 14. إحصاءات مفصلة | تكلفة الذكاء الاصطناعي والإنفاق حسب النموذج والمحادثة وزمن الرد والأخطاء |
| 15. فحص الميزات | ما يعمل وما لا يعمل ولماذا، مع أزرار للإصلاح |

أيضًا: تفريغ الرسائل الصوتية (Whisper عبر Groq)، وأداة على الشاشة الرئيسية، وإشعار دائم، ومربع في الإعدادات السريعة، والأمر `/ai_off` ليوقف الطرف الآخر الردود، وساعات الهدوء، والرد الموحد على عدة رسائل.

## المتطلبات

- أندرويد 9 أو أحدث.
- خادم VPS بنظام Debian 12 أو Ubuntu 24.04 مع IPv4 عام ووصول SSH بصلاحية root.
- قيم `api_id` و`api_hash` الخاصة بك من [my.telegram.org](https://my.telegram.org) (غير مطلوبة للرد من الإشعارات).
- مفتاح API لذكاء اصطناعي: **Groq** (توجد خطة مجانية)، أو **Google Gemini**، أو **GigaChat**، أو أي **API متوافق مع OpenAI** (مثل OpenRouter).

## البدء السريع

1. نزّل ملف APK من صفحة **Releases** وثبّته.
2. **1. الاتصال بـ VPS**: أدخل العنوان وكلمة مرور root، ثم اضغط «تثبيت الخادم من التطبيق».
3. **2. Telegram**: أدخل `api_id` و`api_hash` ورقمك وسجّل الدخول برمز أو QR، أو افتح «الرد من الإشعارات» للعمل دون تسجيل دخول.
4. **3. الذكاء الاصطناعي والنص**: اختر المزوّد والمفتاح والنموذج، واكتب التعليمات، واضغط «اختبار». يمكنك اختيار أسلوب.
5. **4. المحادثات الخاصة**: حدّد جهات الاتصال.
6. **5. المجيب الآلي**: شغّله.

إذا لم يعمل شيء، افتح **15. فحص الميزات** لترى السبب وما يجب فعله.

## الخصوصية والاستخدام المسؤول

- تُرسل الرسائل فقط إلى مزوّد الذكاء الاصطناعي الذي اخترته ومن المحادثات المختارة فقط. التفاصيل: [PRIVACY.md](../../PRIVACY.md)، [SECURITY.md](../../SECURITY.md).
- أخبر جهات اتصالك أن الذكاء الاصطناعي قد يرد عليهم، ولا تحمّل سجلهم دون موافقتهم.
- التزم [بشروط Telegram API](https://core.telegram.org/api/terms): لا رسائل مزعجة ولا إرسال جماعي.
