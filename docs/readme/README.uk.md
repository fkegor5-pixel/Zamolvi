# Zamolvi

[English](../../README.md) · [Русский](README.ru.md) · [Español](README.es.md) · [Português](README.pt.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [Türkçe](README.tr.md) · [Polski](README.pl.md) · **Українська** · [العربية](README.ar.md) · [हिन्दी](README.hi.md) · [Bahasa Indonesia](README.id.md) · [中文](README.zh.md) · [日本語](README.ja.md)

**AI-автовідповідач для особистих чатів Telegram, який працює на вашому власному сервері.**

Zamolvi відповідає співрозмовникам, поки ви зайняті: отримує нове повідомлення, передає його обраній нейромережі й надсилає відповідь від вашого імені — лише в тих особистих чатах, які ви обрали. Керування — з Android-застосунку, а сама робота йде на вашому VPS, тож застосунок можна закрити, а телефон — заблокувати.

## Можливості

| Розділ | Що робить |
|---|---|
| 1. Підключення до VPS | Встановлює й оновлює сервер на VPS через SSH, налаштовує HTTPS |
| 2. Telegram | Вхід в акаунт за кодом або QR, із хмарним паролем. Там само — **відповіді зі сповіщень** без входу в Telegram на сервері |
| 3. Нейромережа і текст | Провайдер, модель, ключ, інструкція й оформлення, перевірка. Там само — **стиль спілкування**: добрий, зухвалий, гопник, розумник, пірат, комп'ютер та інші |
| 4. Особисті чати | Кому відповідає автовідповідач |
| 5. Автовідповідач | Увімкнення й зупинка, статус, тихі години, очікування кількох повідомлень |
| 6. Журнал сервера | Події та діагностика |
| 7. Як це працює | Про застосунок і автора |
| 8. Статистика | Відповіді, голосові й помилки за днями |
| 9. Тема застосунку | Світла, темна або системна. Там само — **мова інтерфейсу** |
| 10. Видалені повідомлення | Архів повідомлень, видалених у вибраних чатах (до 30 днів), із пошуком |
| 11. Пам'ять співрозмовників | Коротке резюме про кожного: ім'я, інтереси, домовленості, факти; кнопка «Забути»; завантаження історії за вашою командою |
| 12. Фото і документи | Текст і опис фото; читання PDF, DOCX, TXT, CSV, JSON |
| 13. Погодження відповідей | Чернетки: надіслати, виправити чи відхилити перед надсиланням |
| 14. Детальна статистика | Вартість AI, витрати за моделями й чатами, час відповіді, помилки |
| 15. Перевірка функцій | Що працює, що ні і чому — з кнопками виправлення |

Також: розшифровка голосових (Whisper через Groq), віджет, сповіщення і плитка швидких налаштувань, команда `/ai_off` для співрозмовника, тихі години й спільна відповідь на кілька повідомлень.

## Що потрібно

- Android 9 або новіший.
- VPS із Debian 12 або Ubuntu 24.04, публічною IPv4 і SSH-доступом від root.
- Власні `api_id` та `api_hash` Telegram з [my.telegram.org](https://my.telegram.org) (не потрібні для відповідей зі сповіщень).
- Ключ AI API: **Groq** (є безкоштовний тариф), **Google Gemini**, **GigaChat** або будь-який **OpenAI-сумісний API** (наприклад, OpenRouter).

## Швидкий старт

1. Завантажте APK зі сторінки **Releases** і встановіть.
2. **1. Підключення до VPS**: введіть адресу й root-пароль, натисніть «Встановити сервер із застосунку».
3. **2. Telegram**: введіть `api_id`, `api_hash` і номер, увійдіть за кодом або QR. Або відкрийте «Відповіді зі сповіщень», щоб працювати без входу.
4. **3. Нейромережа і текст**: оберіть провайдера, ключ і модель, напишіть інструкцію й натисніть «Перевірити». За бажання оберіть стиль.
5. **4. Особисті чати**: позначте співрозмовників.
6. **5. Автовідповідач**: увімкніть.

Якщо щось не працює, відкрийте **15. Перевірка функцій**: там написано причину й що зробити.

## Конфіденційність і відповідальне використання

- Повідомлення йдуть лише обраному AI-провайдеру й лише з вибраних чатів. Детальніше: [PRIVACY.md](../../PRIVACY.md), [SECURITY.md](../../SECURITY.md).
- Попередьте співрозмовників, що їм може відповідати AI, і не завантажуйте їхню історію без згоди.
- Дотримуйтесь [умов Telegram API](https://core.telegram.org/api/terms): жодного спаму й масових розсилок.
