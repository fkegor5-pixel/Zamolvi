## Zamolvi 3.1

### Новое: ответы из уведомлений
Автоответчик теперь может работать **без входа в Telegram на сервере**. Откройте «2. Telegram» → «Ответы из уведомлений»:

1. Дайте приложению доступ к уведомлениям (на Android 13+ при установке не из магазина сначала: «О приложении» → ⋮ → «Разрешить ограниченные настройки»).
2. Впишите имена чатов, как они видны в уведомлениях Telegram.
3. Включите переключатель.

Когда приходит сообщение из чата списка, сервер составляет ответ выбранной нейросетью, и он отправляется кнопкой «Ответить» прямо из уведомления. Работает, пока телефон включён и в сети; в Telegram должен быть включён показ текста в уведомлениях.

### Обновление
Установите `Zamolvi-3.1.apk` поверх 3.0 и обновите сервер в «15. Проверка функций» — новой функции нужен сервер 3.1.0.
