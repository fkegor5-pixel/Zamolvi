## Zamolvi 4.0.1

Внутри — сервер 3.4.1. После установки APK переустановите сервер из приложения или обновите его командой `update.sh`.

- «mute» / «/mute» в личном чате: новые сообщения собеседника удаляются у всех; «unmute» — снять.
- «/ai-on» и «/ai-off» в «Избранном» включают и выключают автоответчик.
- Проверка в приложении сообщает, если на сервере старая версия без этих команд.
