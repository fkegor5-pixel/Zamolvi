## Zamolvi 4.0.3

Внутри — сервер 3.4.3. После установки APK переустановите сервер из приложения.

- «pgl плей-офф»: в полуфинал и финал проходят победители предыдущих матчей. Раньше в финал мог попасть посторонний матч по времени.
- Список «команды»: нажмите на любую команду — она скопируется.
- «mute» / «unmute», «/ai-on» / «/ai-off».
