## Zamolvi 3.3.1

### Стили-персонажи
В «3. Нейросеть и текст» → «Стиль общения» добавлены:
- **Компьютер** — отвечает двоичным кодом (UTF-8), прочитать сможет только тот, кто расшифрует;
- **Болотный огр** — ворчливый добряк с болота;
- **Зелёный громила** — КОРОТКО, КАПСОМ, В ТРЕТЬЕМ ЛИЦЕ;
- **Пират**, **Рыцарь**, **Мудрый магистр**, **Мультяшный злодей**, **Кот**.

### Обновление
Установите APK поверх и обновите сервер в «15. Проверка функций» — нужен сервер 3.2.1.
