## Zamolvi 4.0.2

Внутри — сервер 3.4.2. После установки APK переустановите сервер из приложения.

- Список «команды»: нажмите на любую команду — она скопируется. Синих ссылок больше нет.
- «mute» / «/mute» в личном чате: новые сообщения собеседника удаляются у всех; «unmute» — снять.
- «/ai-on» и «/ai-off» в «Избранном» включают и выключают автоответчик.
