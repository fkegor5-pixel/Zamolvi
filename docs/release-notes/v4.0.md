## Zamolvi 4.0 (тестовая)

**💡 Подсказки.** Новый пункт в группе «Приложение»: где арендовать сервер, какие нейросети
бесплатны, как экономить лимиты, защитить сервер и не получить ограничения. Открываются на сутки
после короткой рекламы Рекламной сети Яндекса. Если реклама не загрузилась — открываются бесплатно.

**Новая сборка.** Приложение пересобрано заново как обычный Android-проект. Функции и меню прежние,
подпись та же — устанавливайте APK поверх 3.8, данные сохранятся.

Реклама показывается только в «Подсказках» и только по вашей кнопке. Что получает Яндекс —
в [PRIVACY.md](https://github.com/fkegor5-pixel/Zamolvi/blob/main/PRIVACY.md). Сервер не меняется.
