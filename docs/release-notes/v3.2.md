## Zamolvi 3.2

Ответы из уведомлений («2. Telegram» → «Ответы из уведомлений»):
- **Всем личным чатам** — новый переключатель: отвечает всем, кроме тех, кто в игноре.
- **Кому ответил** — список собеседников: сколько ответов и когда последний; кнопка «В игнор».
- **Игнор** — кому не отвечать; «Убрать из игнора» возвращает собеседника.
- Служебный чат «Telegram» (коды входа) никогда не уходит на сервер.

Установите APK поверх; сервер обновлять не нужно.
