# Видео-заставка (необязательно)

При нажатии «5. Автоответчик» приложение может показать короткое видео поверх
раздела управления. В репозиторий видео не входит.

Чтобы добавить своё:

1. Положите файл сюда под именем `intro.mp4`.
2. Используйте только видео, на которое у вас есть права: снятое вами или с
   лицензией, разрешающей распространение. Чужие ролики из соцсетей не подойдут.
3. Формат: H.264 (Baseline или Main) + AAC, до 15 секунд, до ~2 МБ.

Файл `assets/*.mp4` указан в `.gitignore`, поэтому он не попадёт в репозиторий
случайно. Без видео кнопка просто открывает раздел управления.
