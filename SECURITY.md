# Безопасность

## Как сообщить об уязвимости

Не публикуйте уязвимость в открытых Issues. Напишите автору в Telegram:
[@stytam](https://t.me/stytam) — опишите проблему, версии приложения и сервера
и шаги для воспроизведения.

## Как устроена защита

- Приложение подключается к серверу только по HTTPS и передаёт ключ управления
  в заголовке. Без ключа API сервера недоступен.
- При первом SSH-подключении приложение показывает отпечаток ключа сервера и
  запоминает его. Если ключ потом изменится, установка будет остановлена.
- Секреты на сервере (сессия Telegram, ключи AI) хранятся в зашифрованном виде;
  служба работает от отдельного системного пользователя с ограничениями systemd.
- Веб-сервер Caddy не ведёт журнал запросов.
- Ключи никогда не попадают в журнал и отчёты диагностики; тексты ошибок
  провайдеров очищаются от похожих на ключи строк.

## Советы по эксплуатации

- Используйте отдельный VPS или хотя бы отдельного пользователя только для Zamolvi.
- После установки отключите вход по паролю для root и войдите по SSH-ключу.
- Не пересылайте никому ключ управления, `api_hash` и ключи AI. Если ключ
  попал в чат или скриншот, сразу отзовите его у провайдера и создайте новый.
- Устанавливайте APK только из Releases этого репозитория или соберите сами.
