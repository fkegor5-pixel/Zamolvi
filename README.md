# Zamolvi

**AI-автоответчик для личных чатов Telegram, который работает на вашем собственном сервере.**

Zamolvi отвечает собеседникам, пока вы заняты: получает новое сообщение, передаёт
его выбранной нейросети и отправляет ответ от вашего имени — только в тех личных
чатах, которые вы выбрали. Управление — из Android-приложения, а сама работа идёт на
вашем VPS, поэтому телефон можно закрыть и заблокировать.

> Название — от «замолвить словечко»: приложение отвечает за вас, пока вас нет.

*English summary: Zamolvi is a self-hosted AI auto-responder for Telegram private chats.
An Android app installs and controls a small Python server (FastAPI + Telethon) on your
own VPS; replies are generated by an AI provider of your choice (Groq, Google Gemini,
GigaChat or any OpenAI-compatible API such as OpenRouter). MIT-licensed.*

## Возможности

Главное меню приложения:

| Раздел | Что делает |
|---|---|
| 1. Подключение к VPS | Устанавливает и обновляет сервер на вашем VPS по SSH, настраивает HTTPS |
| 2. Telegram | Вход в ваш аккаунт: по коду или через QR, с облачным паролем |
| 3. Нейросеть и текст | Провайдер AI, модель, ключ, инструкция для AI и оформление ответов, проверка связи |
| 4. Личные чаты | Выбор собеседников, которым отвечает автоответчик |
| 5. Автоответчик | Включение и остановка, статус, тихие часы, ожидание пачки сообщений |
| 6. Журнал сервера | События и диагностика |
| 7. Как это работает | О приложении и авторе |
| 8. Статистика | Ответы, голосовые и ошибки по дням |
| 9. Тема приложения | Светлая, тёмная или системная |
| 10. Удалённые сообщения | Архив сообщений, удалённых в выбранных чатах (до 30 дней), с поиском |
| 11. Память собеседников | Краткое резюме о каждом собеседнике: имя, интересы, договорённости, важные факты; кнопка «Забыть»; загрузка истории чата по вашей команде |
| 12. Фото и документы | Текст и описание фото, чтение PDF, DOCX, TXT, CSV, JSON |
| 13. Согласование ответов | Черновики: отправить, исправить или отклонить перед отправкой |
| 14. Подробная статистика | Стоимость запросов AI, расходы по моделям и чатам, время ответа, ошибки |
| 15. Проверка функций | Что работает, что нет и почему — с кнопками исправления и отчётом |

Ещё:

- **Голосовые сообщения** расшифровываются (Whisper через Groq), и автоответчик отвечает по их тексту.
- **Виджет на рабочем столе, уведомление в шторке и плитка быстрых настроек**: статус, число отправленных ответов, кнопки «Включить» и «Остановить».
- **Собеседник может сам отключить автоответы** командой `/ai_off`.
- **Тихие часы** в заданном часовом поясе и **пачки сообщений**: автоответчик ждёт несколько секунд и отвечает на несколько сообщений сразу.

## Как это устроено

```
 Android-приложение  ──HTTPS + ключ управления──▶  Ваш VPS (Python: FastAPI + Telethon)
   управление,                                       │            │
   настройки, статус                                 ▼            ▼
                                              Telegram API     AI API
                                              (ваш аккаунт)    (Groq / Gemini / GigaChat /
                                                                OpenAI-совместимый)
```

- Сервер ставится из приложения по SSH одной кнопкой: Python-окружение, служба
  systemd и HTTPS через Caddy.
- Сессия Telegram, ключи API, память и архив хранятся на VPS в зашифрованном виде.
- Приложение общается только с вашим сервером; сторонних серверов у проекта нет.

## Что понадобится

- Android 9 или новее.
- VPS с Debian 12 или Ubuntu 24.04, публичным IPv4 и SSH-доступом от root.
- Собственные `api_id` и `api_hash` Telegram — их выдают на [my.telegram.org](https://my.telegram.org).
- Ключ AI API одного из провайдеров:
  - **Groq** — есть бесплатный тариф с лимитами;
  - **Google Gemini**;
  - **GigaChat**;
  - **любой OpenAI-совместимый API** (например, OpenRouter): адрес вида `https://…/v1/chat/completions`, ключ и идентификатор модели.

## Быстрый старт

1. Скачайте APK со страницы **Releases** и установите его.
2. **1. Подключение к VPS**: введите адрес сервера и пароль root, нажмите
   «Установить сервер из приложения». Приложение проверит ключ SSH сервера и
   попросит подтвердить его отпечаток.
3. **2. Telegram**: введите `api_id`, `api_hash` и номер, затем войдите по
   коду или через QR.
4. **3. Нейросеть и текст**: выберите провайдера, вставьте ключ и модель,
   напишите инструкцию для AI и нажмите «Проверить».
5. **4. Личные чаты**: отметьте собеседников.
6. **5. Автоответчик**: включите.

Если что-то не работает, откройте **15. Проверка функций**: там написана причина и
что сделать.

## Конфиденциальность и безопасность

- Ваша переписка отправляется только выбранному AI-провайдеру и только по
  выбранным чатам. Изучите его правила обработки данных.
- Приложение подключается к серверу по HTTPS с ключом управления; ключ SSH
  сервера закрепляется при первом подключении.
- Подробнее — в [PRIVACY.md](PRIVACY.md) и [SECURITY.md](SECURITY.md).

### Пользуйтесь ответственно

- Предупредите собеседников, что им может отвечать AI. Без их согласия не загружайте их историю переписки в память.
- Автоматизация личного аккаунта должна соответствовать [условиям Telegram API](https://core.telegram.org/api/terms): никакого спама и массовых рассылок. Иначе Telegram может ограничить аккаунт.
- AI может ошибаться. Для важных чатов включите **13. Согласование ответов**.

## Сборка из исходников

Подробно — в [docs/BUILD.md](docs/BUILD.md). Если коротко:

```bash
# JDK 17+, Android SDK (platform 35, build-tools 35), Apktool 3.x
python3 build-tools/build_apk.py --sdk "$ANDROID_HOME" --apktool apktool.jar
# Результат: build/Zamolvi-3.0.apk
```

Готовый APK можно собрать и без компьютера: workflow **Build APK** в GitHub
Actions (вкладка Actions → Build APK → Run workflow).

Тесты сервера:

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r server/requirements.txt -r server/requirements-media.txt -r requirements-dev.txt
pytest
```

## Структура репозитория

| Путь | Содержимое |
|---|---|
| `server/` | Сервер: `replyai/` (код), `tools/` (установка), `deploy/` (служба systemd) |
| `source/` | Экраны и функции Android-приложения (Java) |
| `base/base-app-2.7.apk` | Базовое приложение 2.7: главное меню, VPS, Telegram, AI. Его код не меняется при сборке |
| `compile-api/` | Описания классов базового приложения, нужные только для компиляции |
| `build-tools/` | Скрипт сборки APK и ресурсы виджета |
| `tests/` | Тесты сервера (pytest) |
| `assets/` | Место для необязательного видео-заставки (см. `assets/README.md`) |

Внутренние идентификаторы (Android-пакет `ru.replyai.android`, Python-пакет
`replyai`, каталоги `/opt/replyai` на сервере) остались от прежнего названия
проекта. Они нужны для совместимости: приложение обновляется поверх прежних
версий, а уже установленные серверы продолжают работать.
